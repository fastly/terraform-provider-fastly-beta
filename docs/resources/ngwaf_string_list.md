# fastly_ngwaf_string_list (Resource)

Manages a Fastly Next-Gen WAF `string` list defined at account scope.

Account-scoped NGWAF resources omit `account` from their Terraform names. This
resource manages lists whose entries are exact string values.

Lists of every account list type have their own resource:

- `fastly_ngwaf_ip_list`
- `fastly_ngwaf_string_list`
- `fastly_ngwaf_wildcard_list`
- `fastly_ngwaf_country_list`
- `fastly_ngwaf_signal_list`

All five can be read back together via the `fastly_ngwaf_lists` data source.
For lists owned by one workspace, use the corresponding
`fastly_ngwaf_workspace_*_list` resources instead.

## Example Usage

```terraform
resource "fastly_ngwaf_string_list" "example" {
  name        = "Example String List"
  description = "Managed by Terraform"

  entries = ["admin", "login"]
}
```

## Schema

### Required

- `entries` (List of String) The entries in the string list.
- `name` (String) The name of the string list. Must be between 3 and 32 characters. Changing this attribute will delete and recreate the list.

### Optional

- `description` (String) The description of the list. When set, must be between 3 and 140 characters.

### Read-Only

- `id` (String) The account list identifier generated by Fastly.
- `reference_id` (String) The generated reference ID of the list.

## Import

Next-Gen WAF account string lists are imported using the list ID alone:

```shell
terraform import fastly_ngwaf_string_list.example LIST_ID
```
