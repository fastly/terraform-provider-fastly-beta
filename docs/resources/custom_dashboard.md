# fastly_custom_dashboard (Resource)

Manages a Fastly custom dashboard displayed in the Fastly Observability web interface.

Custom dashboards are versionless and are not attached to a Fastly CDN or Compute
service version. This resource can therefore be used alongside either service
lifecycle family: `fastly_service_cdn_auto` / `fastly_service_compute_auto`, or
the explicit/default service resources.

## Example Usage

```terraform
resource "fastly_custom_dashboard" "example" {
  name        = "Example Custom Dashboard"
  description = "Traffic overview"

  dashboard_item {
    key      = "requests"
    title    = "Total Requests"
    subtitle = "Number of requests processed."
    span     = 4

    data_source {
      type = "stats.edge"

      config {
        metrics = ["requests"]
      }
    }

    visualization {
      config {
        format    = "requests"
        plot_type = "line"
      }
    }
  }
}
```

`dashboard_item.key` is Terraform-owned identity for a dashboard item and is
never sent to Fastly. Fastly assigns the read-only `dashboard_item.id`.
Keeping these concepts separate allows items to be updated or reordered without
requiring users to manufacture API identifiers.

## Schema

### Required

- `name` (String) A human-readable name for the custom dashboard.

### Optional

- `dashboard_item` (Block List) Dashboard items displayed in this custom dashboard. Items are ordered. `key` is Terraform-owned identity; `id` is generated by Fastly. (see [below for nested schema](#nestedblock--dashboard_item))
- `description` (String) A short description of the dashboard.

### Read-Only

- `id` (String) Dashboard identifier generated by Fastly.

<a id="nestedblock--dashboard_item"></a>
### Nested Schema for `dashboard_item`

Required:

- `key` (String) Stable Terraform identity for this dashboard item. Must be unique within the dashboard. Changing it causes the item to be treated as a new item.
- `subtitle` (String) A human-readable subtitle for the dashboard item. Often a description of the visualization.
- `title` (String) A human-readable title for the dashboard item.

Optional:

- `data_source` (Block List) Data source displayed by this dashboard item. (see [below for nested schema](#nestedblock--dashboard_item--data_source))
- `span` (Number) Number of columns the item spans on the dashboard's 12-column grid. Defaults to 4.
- `visualization` (Block List) Visualization used to display the dashboard item. (see [below for nested schema](#nestedblock--dashboard_item--visualization))

Read-Only:

- `id` (String) Dashboard item identifier generated by Fastly. This value is read-only and must not be configured.

<a id="nestedblock--dashboard_item--data_source"></a>
### Nested Schema for `dashboard_item.data_source`

Required:

- `type` (String) The source of the data to display.

Optional:

- `config` (Block List) Configuration options for the selected data source. (see [below for nested schema](#nestedblock--dashboard_item--data_source--config))

<a id="nestedblock--dashboard_item--data_source--config"></a>
### Nested Schema for `dashboard_item.data_source.config`

Required:

- `metrics` (List of String) The metrics to visualize. Valid options are defined by the selected data source: [stats.edge](https://www.fastly.com/documentation/reference/api/observability/custom-dashboards/metrics/edge/), [stats.domain](https://www.fastly.com/documentation/reference/api/observability/custom-dashboards/metrics/domain/), [stats.origin](https://www.fastly.com/documentation/reference/api/observability/custom-dashboards/metrics/origin/).



<a id="nestedblock--dashboard_item--visualization"></a>
### Nested Schema for `dashboard_item.visualization`

Optional:

- `config` (Block List) Configuration options for the chart visualization. (see [below for nested schema](#nestedblock--dashboard_item--visualization--config))

<a id="nestedblock--dashboard_item--visualization--config"></a>
### Nested Schema for `dashboard_item.visualization.config`

Required:

- `plot_type` (String) The type of chart to display. One of: `line`, `bar`, `single-metric`, `donut`.

Optional:

- `calculation_method` (String) The aggregation function to apply to the dataset. One of: `avg`, `sum`, `min`, `max`, `latest`, `p95`.
- `format` (String) The units to use to format the data. Defaults to `number`. One of: `number`, `bytes`, `percent`, `requests`, `responses`, `seconds`, `milliseconds`, `ratio`, `bitrate`.

## Import

Custom dashboards are imported by their Fastly dashboard ID:

```shell
terraform import fastly_custom_dashboard.example DASHBOARD_ID
```

When importing an existing dashboard, the provider initially seeds each item's
Terraform `key` from that item's Fastly-generated `id`, because Fastly does not
store Terraform's configuration-only key. On the first apply after import, an
unchanged item may adopt a friendly configured `key` while preserving its
existing Fastly `id`. The provider only performs this adoption when the imported
item can be matched unambiguously.

## Dashboard item identity

Each dashboard item has two distinct identifiers:

- `key` is required configuration and is owned by Terraform. It must be unique
  within the dashboard and remains stable across ordinary edits and reordering.
- `id` is computed and owned by Fastly. It is assigned by the API when an item
  is created and is reused by the provider for subsequent updates.

Changing `key` causes Terraform to treat the item as a new logical dashboard
item. The provider omits an API ID for that new item and Fastly assigns a new
one.
