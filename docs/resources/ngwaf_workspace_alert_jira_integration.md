# fastly_ngwaf_workspace_alert_jira_integration (Resource)

Manages a Fastly Next-Gen WAF `jira` alert integration scoped to a single workspace.

Workspace alert integrations are versionless and belong to an NGWAF workspace, not to a Fastly service version. Alert integrations of other types are managed by their own `fastly_ngwaf_workspace_alert_*_integration` resources.

## Example Usage

```terraform
resource "fastly_ngwaf_workspace" "example" {
  name        = "Example Workspace"
  description = "Managed by Terraform"
  mode        = "block"

  attack_signal_thresholds {}
}

resource "fastly_ngwaf_workspace_alert_jira_integration" "example" {
  workspace_id = fastly_ngwaf_workspace.example.id
  description  = "Managed by Terraform"

  host         = "https://example.atlassian.net"
  username     = "terraform"
  project      = "TF"
  key          = "1234567890abcdef1234567890abcdef"
  issue_type   = "Task"
}
```

## Schema

### Required

- `host` (String) Host name of the Jira instance.
- `key` (String, Sensitive) Jira API key.
- `project` (String) Specifies the Jira project where the issue will be created.
- `username` (String) Jira username of the user who created the ticket.
- `workspace_id` (String) The ID of the workspace that owns the alert integration.

### Optional

- `description` (String) The description of the jira alert integration. Changing this attribute will delete and recreate the alert integration.
- `issue_type` (String) The Jira issue type associated with the ticket.

### Read-Only

- `id` (String) The workspace alert integration identifier generated by Fastly.

## Import

Next-Gen WAF workspace jira alert integrations are imported using a combination
of the workspace ID and alert integration ID, separated by a `/`:

```shell
terraform import fastly_ngwaf_workspace_alert_jira_integration.example WORKSPACE_ID/ALERT_ID
```
