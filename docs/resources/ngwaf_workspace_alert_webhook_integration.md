# fastly_ngwaf_workspace_alert_webhook_integration (Resource)

Manages a Fastly Next-Gen WAF `webhook` alert integration scoped to a single workspace.

Workspace alert integrations are versionless and belong to an NGWAF workspace, not to a Fastly service version. Alert integrations of other types are managed by their own `fastly_ngwaf_workspace_alert_*_integration` resources.

## Example Usage

```terraform
resource "fastly_ngwaf_workspace" "example" {
  name        = "Example Workspace"
  description = "Managed by Terraform"
  mode        = "block"

  attack_signal_thresholds {}
}

resource "fastly_ngwaf_workspace_alert_webhook_integration" "example" {
  workspace_id = fastly_ngwaf_workspace.example.id
  description  = "Managed by Terraform"

  authentication = {
    webhook = "https://example.com/webhooks/my-service"
  }
}
```

## Schema

### Required

- `authentication` (Attributes) Sensitive configuration for the webhook alert integration. (see [below for nested schema](#nestedatt--authentication))
- `workspace_id` (String) The ID of the workspace that owns the alert integration.

### Optional

- `description` (String) The description of the webhook alert integration. Changing this attribute will delete and recreate the alert integration.

### Read-Only

- `id` (String) The workspace alert integration identifier generated by Fastly.

<a id="nestedatt--authentication"></a>
### Nested Schema for `authentication`

Required:

- `webhook` (String, Sensitive) Webhook URL.

## Import

Next-Gen WAF workspace webhook alert integrations are imported using a combination
of the workspace ID and alert integration ID, separated by a `/`:

```shell
terraform import fastly_ngwaf_workspace_alert_webhook_integration.example WORKSPACE_ID/ALERT_ID
```
