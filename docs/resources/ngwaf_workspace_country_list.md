# fastly_ngwaf_workspace_country_list (Resource)

Manages a Fastly Next-Gen WAF `country` list scoped to a single workspace.

Workspace lists are versionless and belong to an NGWAF workspace, not to a
Fastly service version. This resource manages lists whose entries are country codes.

Lists of other types are managed by their own resources:

- `fastly_ngwaf_workspace_ip_list`
- `fastly_ngwaf_workspace_string_list`
- `fastly_ngwaf_workspace_wildcard_list`
- `fastly_ngwaf_workspace_country_list`
- `fastly_ngwaf_workspace_signal_list`

All five can be read back together via the `fastly_ngwaf_workspace_lists` data
source.

## Example Usage

```terraform
resource "fastly_ngwaf_workspace" "example" {
  name        = "Example Workspace"
  description = "Managed by Terraform"
  mode        = "block"

  attack_signal_thresholds {}
}

resource "fastly_ngwaf_workspace_country_list" "example" {
  workspace_id = fastly_ngwaf_workspace.example.id
  name         = "Example Country List"
  description  = "Managed by Terraform"

  entries = ["US", "DE"]
}
```

## Schema

### Required

- `entries` (List of String) The entries in the country list.
- `name` (String) The name of the country list. Must be between 3 and 32 characters. The name is immutable after creation.
- `workspace_id` (String) The ID of the workspace that owns the list.

### Optional

- `description` (String) The description of the list. When set, must be between 3 and 140 characters.

### Read-Only

- `id` (String) The workspace list identifier generated by Fastly.
- `reference_id` (String) The generated reference ID of the list.

## Import

Next-Gen WAF workspace country lists are imported using a combination of the
workspace ID and the list ID, separated by a `/`:

```shell
terraform import fastly_ngwaf_workspace_country_list.example WORKSPACE_ID/LIST_ID
```
