# fastly_ngwaf_workspace_alert_datadog_integration (Resource)

Manages a Fastly Next-Gen WAF `datadog` alert integration scoped to a single workspace.

Workspace alert integrations are versionless and belong to an NGWAF workspace, not to a Fastly service version. Alert integrations of other types are managed by their own `fastly_ngwaf_workspace_alert_*_integration` resources.

## Example Usage

```terraform
resource "fastly_ngwaf_workspace" "example" {
  name        = "Example Workspace"
  description = "Managed by Terraform"
  mode        = "block"

  attack_signal_thresholds {}
}

resource "fastly_ngwaf_workspace_alert_datadog_integration" "example" {
  workspace_id = fastly_ngwaf_workspace.example.id
  description  = "Managed by Terraform"

  key          = "1234567890abcdef1234567890abcdef"
  site         = "us1"
}
```

## Schema

### Required

- `key` (String, Sensitive) Datadog API key.
- `site` (String) Datadog site to use. One of `us1`, `us3`, `us5`, or `eu1`.
- `workspace_id` (String) The ID of the workspace that owns the alert integration.

### Optional

- `description` (String) The description of the datadog alert integration. Changing this attribute will delete and recreate the alert integration.

### Read-Only

- `id` (String) The workspace alert integration identifier generated by Fastly.

## Import

Next-Gen WAF workspace datadog alert integrations are imported using a combination
of the workspace ID and alert integration ID, separated by a `/`:

```shell
terraform import fastly_ngwaf_workspace_alert_datadog_integration.example WORKSPACE_ID/ALERT_ID
```
