# fastly_alert (Resource)

Provides a Fastly Alert. Alerts send notifications to custom integrations (e.g., Slack
channels, PagerDuty, Microsoft Teams and New Relic) when an observed metric either exceeds
or falls below a threshold.

Alerts are versionless and independent of any service-version lifecycle: creating,
updating, or deleting an alert never clones or activates a new service version.

An alert's `source` determines whether `service_id` is required:

- `domains` and `origins` alerts monitor a specific service, so `service_id` is required.
- `stats` alerts can either monitor a specific service (`service_id` set) or aggregate
  across the whole account (`service_id` omitted).

## Example Usage

### Alert scoped to a service

```terraform
resource "fastly_service_cdn" "example" {
  name    = "my_vcl_service"
  version = 1

  force_destroy = true
}

resource "fastly_service_domain" "example" {
  service_id = fastly_service_cdn.example.id
  version    = fastly_service_cdn.example.version

  name = "demo.notexample.com"
}

resource "fastly_alert" "example" {
  name       = "${fastly_service_cdn.example.name} errors"
  service_id = fastly_service_cdn.example.id
  source     = "stats"
  metric     = "status_5xx"

  evaluation_strategy {
    type      = "above_threshold"
    period    = "5m"
    threshold = 10
  }
}
```

### Account-wide alert

Omitting `service_id` is only supported when `source` is `stats`:

```terraform
resource "fastly_alert" "account_wide" {
  name   = "account-wide 4xx rate"
  source = "stats"
  metric = "status_4xx"

  evaluation_strategy {
    type         = "percent_increase"
    period       = "2m"
    threshold    = 0.25
    ignore_below = 10
  }
}
```

### Alert restricted to specific domains

```terraform
resource "fastly_alert" "domain_scoped" {
  name       = "checkout domain errors"
  service_id = fastly_service_cdn.example.id
  source     = "domains"
  metric     = "status_5xx"

  dimensions {
    domains = ["checkout.example.com"]
  }

  evaluation_strategy {
    type      = "above_threshold"
    period    = "5m"
    threshold = 10
  }
}
```

## Schema

### Required

- `metric` (String) The metric name to alert on for a specific source: [domains](https://developer.fastly.com/reference/api/metrics-stats/domain-inspector/historical), [origins](https://developer.fastly.com/reference/api/metrics-stats/origin-inspector/historical), or [stats](https://developer.fastly.com/reference/api/metrics-stats/historical-stats).
- `name` (String) The name of the alert definition.
- `source` (String) The service on which the definition will alert on. One of: `domains`, `origins`, `stats`.

### Optional

- `description` (String) Additional text that is included in the alert notification.
- `dimensions` (Block List) More filters depending on the source type. (see [below for nested schema](#nestedblock--dimensions))
- `evaluation_strategy` (Block List) Criteria on how to alert. Exactly one block is required. (see [below for nested schema](#nestedblock--evaluation_strategy))
- `integration_ids` (Set of String) List of integrations used to notify when alert fires.
- `service_id` (String) The service which the alert monitors. Optional when using `stats` as the `source`.

### Read-Only

- `id` (String) The alphanumeric string identifying the alert definition, generated by Fastly.

<a id="nestedblock--dimensions"></a>
### Nested Schema for `dimensions`

Optional:

- `domains` (Set of String) Names of a subset of domains that the alert monitors.
- `origins` (Set of String) Addresses of a subset of backends that the alert monitors.


<a id="nestedblock--evaluation_strategy"></a>
### Nested Schema for `evaluation_strategy`

Required:

- `period` (String) The length of time to evaluate whether the conditions have been met. The data is polled every minute. One of: `2m`, `3m`, `5m`, `15m`, `30m`.
- `threshold` (Number) Threshold used to alert.
- `type` (String) Type of strategy to use to evaluate. One of: `above_threshold`, `all_above_threshold`, `below_threshold`, `percent_absolute`, `percent_decrease`, `percent_increase`.

Optional:

- `ignore_below` (Number) Threshold for the denominator value used in evaluations that calculate a rate or ratio. Usually used to filter out noise.

## Import

Fastly Alerts can be imported using their alert definition ID:

```shell
terraform import fastly_alert.example <alert_definition_id>
```
