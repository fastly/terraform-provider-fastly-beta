# fastly_ngwaf_workspace_alert_mailing_list_integration (Resource)

Manages a Fastly Next-Gen WAF `mailinglist` alert integration scoped to a single workspace.

Workspace alert integrations are versionless and belong to an NGWAF workspace, not to a Fastly service version. Alert integrations of other types are managed by their own `fastly_ngwaf_workspace_alert_*_integration` resources.

## Example Usage

```terraform
resource "fastly_ngwaf_workspace" "example" {
  name        = "Example Workspace"
  description = "Managed by Terraform"
  mode        = "block"

  attack_signal_thresholds {}
}

resource "fastly_ngwaf_workspace_alert_mailing_list_integration" "example" {
  workspace_id = fastly_ngwaf_workspace.example.id
  description  = "Managed by Terraform"

  address      = "alerts@example.com"
}
```

## Schema

### Required

- `address` (String, Sensitive) Email address that receives alert notifications.
- `workspace_id` (String) The ID of the workspace that owns the alert integration.

### Optional

- `description` (String) The description of the mailinglist alert integration. Changing this attribute will delete and recreate the alert integration.

### Read-Only

- `id` (String) The workspace alert integration identifier generated by Fastly.

## Import

Next-Gen WAF workspace mailinglist alert integrations are imported using a combination
of the workspace ID and alert integration ID, separated by a `/`:

```shell
terraform import fastly_ngwaf_workspace_alert_mailing_list_integration.example WORKSPACE_ID/ALERT_ID
```
