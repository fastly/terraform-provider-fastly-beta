# fastly_ngwaf_workspace_threshold (Resource)

Manages a Fastly Next-Gen WAF threshold within a workspace.

A threshold triggers an action when a signal is detected more than `limit`
times within `interval` seconds from the same IP address, or immediately
when `action` is `block_immediately`.

## Example Usage

```terraform
resource "fastly_ngwaf_workspace" "example" {
  name        = "Example Workspace"
  description = "Managed by Terraform"
  mode        = "block"
}

resource "fastly_ngwaf_workspace_threshold" "example" {
  workspace_id = fastly_ngwaf_workspace.example.id

  name        = "Example Threshold"
  action      = "block"
  signal      = "SQLI"
  enabled     = true
  dont_notify = false
  interval    = 3600
  limit       = 10
  duration    = 86400
}
```

## Schema

### Required

- `action` (String) Action to take when threshold is exceeded. One of `block`, `block_immediately`, or `log`.
- `dont_notify` (Boolean) Whether to silence notifications when action is taken.
- `enabled` (Boolean) Whether this threshold is active.
- `name` (String) The name of the threshold. Must be between 3 and 50 characters.
- `signal` (String) The name of the signal this threshold is acting on.
- `workspace_id` (String) The ID of the workspace this threshold belongs to.

### Optional

- `duration` (Number) Duration the action is in place, in seconds. Minimum `1` and maximum `31556900`. Defaults to `86400` (1 day).
- `interval` (Number) Threshold interval in seconds. One of `60`, `600`, or `3600`. Defaults to `3600` (1 hour).
- `limit` (Number) Threshold limit. Minimum `1` and maximum `100000`. Defaults to `10`.

### Read-Only

- `id` (String) The Next-Gen WAF threshold identifier generated by Fastly.

## Import

Next-Gen WAF thresholds are imported using their workspace and threshold ID:

```shell
terraform import fastly_ngwaf_workspace_threshold.example <workspace_id>/<threshold_id>
```
