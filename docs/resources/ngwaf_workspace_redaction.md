# fastly_ngwaf_workspace_redaction (Resource)

Manages a Fastly Next-Gen WAF field redaction scoped to a single workspace.

Redactions prevent a specific request parameter, request header, or response
header from being logged or displayed. Workspace redactions are versionless
and belong to an NGWAF workspace, not to a Fastly service version.

## Example Usage

```terraform
resource "fastly_ngwaf_workspace" "example" {
  name        = "Example Workspace"
  description = "Managed by Terraform"
  mode        = "block"

  attack_signal_thresholds {}
}

resource "fastly_ngwaf_workspace_redaction" "example" {
  workspace_id = fastly_ngwaf_workspace.example.id
  field        = "credit_card_number"
  type         = "request_parameter"
}
```

## Schema

### Required

- `field` (String) The name of the field that should be redacted.
- `type` (String) The type of field that is being redacted. Accepted values are `request_parameter`, `request_header`, and `response_header`.
- `workspace_id` (String) The ID of the workspace that owns the redaction.

### Read-Only

- `id` (String) A base62-encoded representation of a UUID used to uniquely identify a redaction generated by Fastly.

## Import

Workspace redactions are imported using a combination of the workspace ID and
the redaction ID, separated by a `/`:

```shell
terraform import fastly_ngwaf_workspace_redaction.example WORKSPACE_ID/REDACTION_ID
```
